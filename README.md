# 局域网快传（lan-msg-share）

一个开箱即用的 **局域网文件 + 文本互传** 小工具。在电脑上运行一个 Flask 服务，同一 Wi‑Fi 下的手机、平板、其它电脑用浏览器打开页面，就能互相传文件、共享粘贴板文本。

无需注册、无需安装 App、无需公网、数据不经过任何第三方服务器。

## 功能特性

- **文件互传**：拖拽或点击上传，支持一次多选、实时进度条、下载与删除；同名文件自动改名，不会覆盖。
- **共享粘贴板**：在页面上发送一段文本，同一局域网内所有打开页面的人约 2 秒内自动看到，可一键复制或单条删除。
- **扫码即用**：服务启动后页面自动生成局域网地址二维码，手机扫码直接进入。
- **自适应排版**：深色玻璃拟态界面，电脑端双栏卡片布局，手机端自动切换为单栏。
- **纯本地运行**：文件只落盘到本机 `uploads/`，文本只写入本机 `clipboard.json`，不上传云端。
- **零前端依赖**：单个 Flask 文件 + 原生 HTML/CSS/JS，依赖只有 Flask、qrcode、Pillow。

## 上传的文件存在哪个文件夹？

**所有通过页面上传的文件，都保存在项目根目录下的 `uploads/` 文件夹里**，也就是 `app.py` 同级的 `uploads` 目录：

```
lan-msg-share/
├── app.py
├── uploads/          ← ★ 上传的文件都保存在这里
│   ├── 照片.jpg
│   └── 报告.pdf
└── ...
```

- 部署在别处时，实际路径就是「`app.py` 所在目录 + `uploads`」，例如 `D:\lan-msg-share\uploads\`。
- 同名文件不会覆盖，会自动追加序号，如 `报告_1.pdf`。
- 共享粘贴板的文本保存在根目录的 `clipboard.json` 中（首次发送文本时自动创建）。
- 这两个位置都可以随时手动清理；`uploads/` 里的文件也会出现在页面「已分享文件」列表中，删文件建议直接在页面上点删除。

## 环境要求

- Python 3.9 及以上
- 电脑与手机 / 平板连接同一个局域网（同一 Wi‑Fi，或同一路由器的有线/无线网络）

## 安装与启动

```bash
# 1. 克隆代码
git clone https://github.com/jixui666/lan-msg-share.git
cd lan-msg-share

# 2. 建议使用虚拟环境
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 启动
python app.py
```

启动后终端会打印访问地址，例如：

```
电脑打开:  http://127.0.0.1:5000
手机打开:  http://192.168.1.6:5000
```

## 使用方法

1. **电脑访问**：浏览器打开 `http://127.0.0.1:5000`。
2. **手机访问**：手机连上同一个 Wi‑Fi，扫描页面左上角的二维码；或直接在手机浏览器输入页面上显示的局域网地址（如 `http://192.168.1.6:5000`）。
3. **上传文件**：把文件拖到「拖拽文件到这里」区域，或点击「选择文件」；手机端点击后从相册 / 文件中选择。上传过程有进度条，完成后自动出现在「已分享文件」列表。
4. **下载 / 删除文件**：在「已分享文件」列表中点击下载图标下载，点击垃圾桶图标删除（需确认）。
5. **共享粘贴板**：在输入框粘贴或输入文本，点击「发送到局域网」或按 `Ctrl / ⌘ + Enter`；其他人打开着页面的话约 2 秒内自动出现。每条文本可「复制」或「删除」，右上角「清空」可一次清空全部。
6. **复制访问地址**：点「复制地址」把局域网地址发给别人。

> 提示：页面显示的是第一块网卡的局域网 IP；如果手机打不开，展开「打不开？试试其他地址」换一个地址试试。

## 常用配置

| 需求 | 做法 |
| --- | --- |
| 换端口 | 启动前设置环境变量 `PORT`，如 Windows `set PORT=8000` 后 `python app.py`；macOS/Linux `PORT=8000 python app.py` |
| 换上传目录 | 修改 `app.py` 顶部的 `UPLOAD_DIR` |
| 调整单文件上限 | 修改 `app.py` 中的 `MAX_CONTENT_LENGTH`（默认 2 GB） |
| 调整粘贴板条数 / 长度 | 修改 `MAX_CLIPS`（默认 50 条）、`MAX_CLIP_CHARS`（默认 5 万字） |

## 常见问题

- **手机打不开页面**：确认手机和电脑在同一 Wi‑Fi；确认 Windows 防火墙允许 Python 入站（或临时关闭防火墙试一次）；关闭手机上的 VPN / 代理；换页面里列出的其它 IP 试试。
- **端口 5000 被占用**：换一个端口启动，例如 `set PORT=8000`。
- **上传大文件失败**：检查磁盘空间；确认没有超过 `MAX_CONTENT_LENGTH`（2 GB）。
- **文件去哪了**：见上文，全部在项目根目录的 `uploads/` 文件夹。
- **隐私与安全**：页面没有登录与权限控制，同一网络内任何人都能打开、上传、下载、删除文件。请只在可信的局域网内使用，用完可以停止服务。
- **清空数据**：删除 `uploads/` 里的文件、删除 `clipboard.json` 即可。

## 接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/` | 页面 |
| `GET` | `/api/files` | 文件列表（JSON） |
| `POST` | `/api/upload` | 上传文件（multipart，字段名 `files`，可多个） |
| `GET` | `/download/<文件名>` | 下载文件 |
| `DELETE` | `/api/files/<文件名>` | 删除文件 |
| `GET` | `/api/clips` | 共享文本列表（新的在前） |
| `POST` | `/api/clips` | 发送文本，body `{"text": "..."}` |
| `DELETE` | `/api/clips/<id>` | 删除一条文本 |
| `DELETE` | `/api/clips` | 清空共享文本 |

```
├── templates/

├── static/
│   └── style.css       # 深色玻璃拟态样式，响应式布局
├── uploads/            # ★ 上传的文件保存在这里（已加入 .gitignore）
├── clipboard.json      # 共享粘贴板文本（运行时自动生成，已忽略）
├── requirements.txt    # 依赖：flask / qrcode / pillow
└── README.md
```

## 说明

- 无数据库、无外部服务，适合家里、办公室、教室等可信局域网内快速互传。
- 局域网 IP 由 `app.py` 自动探测；有多块网卡（如 VMware / VPN）时会列出多个候选地址。
